# Manufacturing ERP Pro - Enterprise ERP for WordPress

Manufacturing ERP Pro is a full-featured, modular, and scalable Manufacturing ERP plugin designed for real manufacturing companies. It supports discrete and light process manufacturing and is suitable for SMEs scaling upward.

## 🚀 Quick Start for Local Review

To review this system on your local environment (LocalWP, XAMPP, etc.):

1.  **Download the Repository**: Click the 'Code' button on GitHub and select 'Download ZIP' or clone the repo using `git clone`.
2.  **Locate the Plugin**: The actual WordPress plugin is in the `/manufacturing-erp-pro/` folder.
3.  **Install on Local WordPress**:
    *   Move the `manufacturing-erp-pro` folder into your local site's `wp-content/plugins/` directory.
    *   Log in to your local WordPress Admin.
    *   Navigate to **Plugins** and click **Activate** on "Manufacturing ERP Pro".
4.  **Follow the Setup Wizard**: Upon activation, you will be redirected to the Setup Wizard.
    *   **Pro Tip**: Choose **Demo Mode (LeatherCraft Co.)** to immediately populate your system with sample materials, products, BOMs, and work orders.
5.  **Branding**: Go to **Appearance > Customize > Manufacturing ERP Pro** to set your local factory logo and accent colors.

## 🛠️ Core Modules Included

*   **Engineering**: Visual Drag-and-Drop BOM Builder with real-time cost roll-ups and versioning.
*   **Production**: Kanban-style Work Order management with backflushing and automated QC loops.
*   **Inventory**: Visual Warehouse Layout with bin-level tracking, heatmaps, and reorder alerts.
*   **MRP**: Automated planning engine with demand pegging (linking buy suggestions to specific forecasts).
*   **Quality**: Comprehensive QC, NCR (Non-Conformance Reports), and CAPA (Corrective and Preventive Action) workflows.
*   **Supply Chain**: Supplier scorecards (tracking Quality vs. OTD) and automated PO generation.
*   **Analytics**: Executive dashboards with real-time OTD, Scrap Rate, and Inventory Aging KPIs.

## 📱 Mobile & Shop Floor Ready

The plugin includes frontend portals (`/erp-shop-floor/`) specifically designed for use on tablets by operators and warehouse staff.
