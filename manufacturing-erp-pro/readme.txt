Full-featured Manufacturing ERP for WordPress. Supports discrete and light process manufacturing.

== Description ==

Manufacturing ERP Pro is an enterprise-grade manufacturing resource planning (MRP) system built natively for WordPress. Designed for SMEs scaling upward, it provides a modular and scalable solution to manage factory operations.

Key Features:
* **Visual BOM Builder**: Drag-and-drop materials and operations to build multi-level Bill of Materials with real-time cost roll-ups.
* **Inventory & Warehouse Management**: Real-time tracking by warehouse, bin, and lot. Visual warehouse layout with heatmaps.
* **MRP Engine**: Automated material requirements planning with demand pegging.
* **Production Kanban**: Drag-and-drop work order lifecycle management for the shop floor.
* **Traceability & Quality**: Lot genealogy visualization and QC checkpoint management.
* **Capacity Planning**: Monitor machine load and schedule maintenance.
* **Procurement**: Automated PO generation and supplier performance scorecards.

== Installation ==

1. Upload the `manufacturing-erp-pro` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Follow the Setup Wizard in the ERP Pro menu to configure your factory.

== Frequently Asked Questions ==

= Does it support multi-level BOMs? =
Yes, the system supports recursive BOM structures with nested assemblies.

= Is it mobile friendly? =
Yes, the Kanban and Warehouse interfaces are designed for shop-floor tablets.
